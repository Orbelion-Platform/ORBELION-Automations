# Security

This repository is an educational case study with a local synthetic example. Do not submit credentials, customer data or private infrastructure details in issues or pull requests.

The example accepts only bounded integer counts. It has no network clients, external writes or production authorization. Do not interpret configuration separation in the underlying framework as identity-based tenant isolation.

For a suspected disclosure, use GitHub private vulnerability reporting if enabled; otherwise contact the repository owner through a private channel before sharing sensitive details.
